# 💈 Barber SaaS - صفحة الهبوط ونظام قياس اهتمام السوق

نظام متكامل وخفيف جداً لصفحة هبوط **Barber SaaS** (منصة إدارة صالونات الحلاقة والعناية بالرجل) مجهز بنظام قياس اهتمام العملاء وقاعدة بيانات محلية سريعة ولوحة تحكم وتصدير Excel.

---

## 🌟 الميزات والمواصفات الفنية المطبقة

### 1. التصميم وتجربة المستخدم (UI/UX & Responsiveness)
* **توافق تام 100%**: تصميم متجاوب بدون أي تداخل على الهواتف الذكية (iOS & Android)، الأجهزة اللوحية (iPads/Tablets)، والشاشات المكتبية.
* **دعم 4 لغات**: (العربية، الإنجليزية، الأردية، التاغالوغ) لاستهداف أصحاب الصالونات والحلاقين والعمالة المختلفة بسلاسة وتغيير الاتجاه (RTL/LTR) تلقائياً.
* **سرعة فائقة (< 50ms)**: بدون أي مكتبات خارجية ثقيلة (Pure Semantic HTML5 + Modern CSS + Vanilla JS).

### 2. آلية التفاعل والأزرار (Interactive Logic)
* **زر "أنا مهتم"**:
  * يفتح نافذة تفاعلية منبثقة (Smooth Modal Popup) دون الانتقال لصفحة أخرى.
  * يحتوي على خانة إدخال واحدة فقط: **(أدخل رقم جوالك)**.
  * **التحقق الصارم (Validation)**:
    * يقبل الأرقام فقط (فلترة فورية لأي حروف أو رموز).
    * يبدأ بـ **05**.
    * يتكون من **10 أرقام بالضبط**.
    * **زر الإرسال معطل (Disabled)** ولا يمكن الضغط عليه إلا بعد استيفاء الشروط كاملة وظهور علامة التحقق الخضراء.
  * **رسالة الشكر الفورية**: بمجرد الإرسال تظهر رسالة لطيفة: *"شكراً لانضمامك! سنتواصل معك قريباً جداً"*.
* **زر "غير مهتم"**:
  * عند النقر، يُسجل الاختيار فوراً في قاعدة البيانات.
  * تظهر رسالة شكر قصيرة ومهذبة: *"شكراً لوقتك، نتشرف برأيك ونسعى لتقديم الأفضل دائماً!"*.

### 3. قاعدة البيانات ولوحة التحكم (Backend & Database)
* **قاعدة بيانات خفيفة (SQLite)**: تُحفظ السجلات في ملف `barber_leads.db` متضمناً:
  1. نوع الاختيار (`interested` أو `not_interested`).
  2. رقم الجوال (للعملاء المهتمين).
  3. تاريخ ووقت التفاعل (Timestamp).
  4. عنوان IP والمتصفح / الجهاز (User-Agent).
* **لوحة تحكم مصغرة (Admin Dashboard)** متوفرة على الرابط: `http://localhost:8000/admin`
  * بطاقات إحصائيات حية: إجمالي التفاعلات، عدد المهتمين، عدد غير المهتمين، نسبة التحويل (%).
  * جدول تفاعلي بالبيانات مع إمكانية البحث والفلترة.
  * أزرار تفاعلية سريعة بجانب كل رقم: مراسلة واتساب فورية بنقرة واحدة، نسخ الرقم، والاتصال.
  * **تصدير إلى Excel (CSV)** بترميز UTF-8 مع BOM لضمان فتح النصوص العربية في مايكروسوفت إكسل بشكل سليم وبدون تشفير خاطئ.

## 🚀 طريقة التشغيل

### الطريقة الأولى: بنقرة واحدة على ويندوز
اضغط نقراً مزدوجاً على الملف:
```
run.bat
```
سيقوم ببدء السيرفر وفتح صفحة الهبوط في متصفحك تلقائياً.

### الطريقة الثانية: عبر سطر الأوامر (Terminal)
تأكد من وجود بايثون (لا يتطلب أي مكتبات إضافية نهائياً):
```bash
python app.py
```
